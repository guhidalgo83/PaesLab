## Resultado
- 6 lecciones profundas de 5.º básico.
- 78 bloques pedagógicos.
- 36 ejercicios completamente resueltos.
- 18 ejercicios guiados con pistas.
- 72 preguntas de práctica segura.
- Motor de práctica con respuesta protegida en Supabase.
- Actualización de dominio y recomendaciones.

## Requisitos
Debes tener instalados MathLabs V1, V2 abierto y V3.

## Instalación
1. Descomprime el ZIP en la raíz del proyecto.
2. Ejecuta `bash scripts/install_mathlabs_v4.sh`.
3. En Supabase ejecuta `database/14_mathlabs_first_school_unit.sql`.
4. Ejecuta `database/15_verify_mathlabs_v4.sql`.
5. En Codespaces ejecuta ESLint, TypeScript y build.
